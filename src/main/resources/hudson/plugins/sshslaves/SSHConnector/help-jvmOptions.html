Additional arguments for the JVM, such as -Xmx or GC options.

For example, if an agent process running out of memory should terminate immediately instead of remaining connected in a broken state and failing every build assigned to it, consider adding -XX:OnOutOfMemoryError="kill -9 %p" or -XX:+ExitOnOutOfMemoryError, so Jenkins detects the disconnect and can retry the launch instead of routing builds to a dead agent.
